\# 00 — Índice Mestre | Memória Oficial



Este documento registra a visão geral do projeto Agentes de IA.



\## Objetivo geral



Aprender a construir, avaliar e documentar agentes de IA de forma prática, segura e progressiva.



\## Organização dos chats



1\. 00 — Índice Mestre | Memória Oficial

2\. 01 — Conceitos de Agentes de IA

3\. 02 — Agentes Locais com Ollama

4\. 03 — LangChain e LangGraph

5\. 04 — Avaliar Hermes Agent

6\. 05 — ai-memory | Memória Longa de Agentes

7\. 06 — Arquitetura de Agentes para Projetos Reais

8\. 07 — Prompts, Skills e Instruções

9\. 08 — Projeto Piloto | Agente de Continuidade



\## Eixos do projeto



\### Construção



Construir agentes simples localmente para entender os fundamentos.



\### Avaliação



Avaliar agentes prontos, especialmente Hermes Agent, sem delegar decisões críticas automaticamente.



\### Memória



Estudar memória longa para preservar conhecimento, decisões, procedimentos e handoffs.



\## Regra de segurança inicial



Nenhum agente deve alterar produção, banco de dados, arquivos críticos ou repositórios reais sem revisão humana.



## Fontes principais

### Machine Learning Mastery

Fonte inicial para entender a construção de agentes locais com modelos pequenos, Python, Ollama e ferramentas.

### Hermes Agent

Ferramenta a ser avaliada como agente executor pronto. O foco será entender recursos, riscos, limites, skills, memória e automações.

### ai-memory

Projeto a ser estudado como referência para memória longa, handoff, continuidade e documentação versionada entre agentes e projetos.

## Estratégia de aprendizado

A ordem do estudo será:

1. Entender conceitos.
2. Construir agente simples local.
3. Adicionar ferramentas e memória curta.
4. Estudar LangChain e LangGraph.
5. Avaliar Hermes Agent.
6. Estudar ai-memory.
7. Projetar uma arquitetura segura para uso em projetos reais.
