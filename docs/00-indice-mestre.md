\# 00 — Índice Mestre | Memória Oficial



Este documento registra a visão geral do projeto Agentes de IA.



\## Objetivo geral



Aprender a construir, avaliar e documentar agentes de IA de forma prática, segura e progressiva.

\## Eixos do projeto



\### Construção



Construir agentes simples localmente para entender os fundamentos.



\### Avaliação



Avaliar agentes prontos, especialmente Hermes Agent, sem delegar decisões críticas automaticamente.



\### Memória



Estudar memória longa para preservar conhecimento, decisões, procedimentos e handoffs.



\## Regra de segurança inicial



Nenhum agente deve alterar produção, banco de dados, arquivos críticos ou repositórios reais sem revisão humana.
