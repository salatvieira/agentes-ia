\# Glossário



\## Agente de IA



Sistema que usa um modelo de linguagem para interpretar um objetivo, decidir próximos passos, usar ferramentas e produzir uma resposta ou ação.



\## LLM



Large Language Model. Modelo de linguagem grande, treinado para compreender e gerar texto.



\## SLM



Small Language Model. Modelo de linguagem menor, geralmente mais leve para rodar localmente.



\## Ferramenta



Função externa que o agente pode acionar, como calculadora, busca, leitura de arquivo, terminal ou API.



\## Memória curta



Histórico temporário usado durante uma conversa ou sessão.



\## Memória longa



Conhecimento persistente usado para manter continuidade entre sessões, projetos ou agentes.
