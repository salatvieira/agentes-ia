# Decisões do Projeto

## 2026-10-12 — Início oficial do projeto

O projeto Agentes de IA foi iniciado com o objetivo de estudar, documentar e praticar a construção de agentes de IA.

A trilha será organizada em três eixos:

1. Construção de agentes locais com Python, Ollama, LangChain e LangGraph.
2. Avaliação de agentes executores prontos, começando pelo Hermes Agent.
3. Estudo de memória longa, continuidade, handoff e autoaprendizado com ai-memory.

A rotina definida será de 1h por dia.

O GitHub será usado como fonte técnica versionada do estudo.


## 2026-10-13 — Organização das fontes iniciais

Foram definidas três fontes principais para o ciclo inicial do projeto:

1. Machine Learning Mastery, como ponto de partida para construção de agentes locais.
2. Hermes Agent, como agente executor pronto a ser avaliado.
3. ai-memory, como referência para memória longa, handoff e continuidade entre sessões/agentes.

Decisão importante:

Cada fonte terá um papel específico. O projeto não seguirá uma ferramenta única. A estratégia será aprender os fundamentos, construir experimentos simples, avaliar ferramentas prontas e depois desenhar uma arquitetura segura para uso em projetos reais.
