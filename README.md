# Agentes de IA

Projeto pessoal de estudo e experimentação na construção, avaliação e documentação de agentes de IA.

## Objetivo

Aprender, de forma prática e progressiva, como agentes de IA funcionam, como podem ser construídos localmente, como podem usar ferramentas, memória e bases de conhecimento, e como podem ser aplicados com segurança em projetos reais.

## Eixos de estudo

### 1. Construção de agentes locais

Estudo de agentes usando Python, Ollama, LangChain, LangGraph, ferramentas simples, memória curta e RAG.

### 2. Avaliação de agentes prontos

Avaliação de agentes executores, começando pelo Hermes Agent, observando recursos, riscos, ferramentas, skills, memória e automações.

### 3. Memória longa para agentes

Estudo de memória persistente, handoff, continuidade entre sessões e documentação viva, com foco no projeto ai-memory.

## Estratégia

O projeto será estudado com dedicação diária de 1h, com documentação contínua no GitHub e acompanhamento pessoal no Notion.
